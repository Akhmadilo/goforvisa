# Lavozim saqlanishini tuzatish

## Natija
- Admin kiritgan lavozim bazaga haqiqatan saqlanadi.
- Saqlangach admin ro‘yxati va yuqori burchakdagi profil yozuvi darhol yangilanadi.

## Amalga oshirish
- Lavozimni maxsus yuqori huquqli ulanish bilan emas, tizimga kirgan adminning tasdiqlangan sessiyasi orqali yangilash.
- Mavjud admin tekshiruvi va kompaniya a’zoligi tekshiruvini saqlab qolish.
- Saqlangan qiymatni qaytarib, ekrandagi ma’lumotni darhol yangilash.
- Amaldagi profil xavfsizlik qoidasini o‘zgartirmaslik.

## Tekshiruv
- Lavozim yozib saqlanganda bazadagi qiymat o‘zgarganini tekshirish.
- Sahifadagi ro‘yxat va yuqori burchakda yangi lavozim ko‘rinishini tekshirish.
- Loyiha yig‘ilishida xato yo‘qligini tasdiqlash.
